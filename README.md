# DymicShell

Currently my personal quickshell theme, visually dynamic in transient.

Built-in `matugen` exports also write common theme targets such as GTK, Qt, KDE,
Niri, and Kitty from the active wallpaper palette.

## NetEase Web Lyrics

The supported NetEase web lyrics path is the Firefox extension in
`scripts/firefox-extensions/netease-web-lyrics/README.md:1`.
