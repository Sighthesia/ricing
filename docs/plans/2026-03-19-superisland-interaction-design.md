# SuperIsland 交互设计与架构哲学 (2026-03-19)

## 核心愿景：打破传统桌面“群雄乱舞”的陈旧范式

传统桌面环境（尤其是平铺窗口管理器中）的 UI 设计往往陷入“静态平铺、信息堆砌”的陷阱：系统托盘、通知气泡、媒体控制块、各种挂件都在试图吸引用户的注意力，导致视觉噪音极大。

DymicShell 的核心 UI 哲学是：**动态聚焦、按需呈现**。我们将所有瞬态（Transient）和高优（High-priority）事件收束到 `SuperIslandWidget`（灵动岛），同时为高频操作建立严格的视觉纪律，使得系统既有灵动的视觉亮点，又绝不陷入无序的混乱。

---

## 核心设计规则

### 1. 媒体模块：极致的“隐式控制与肌肉记忆”

彻底抛弃传统的“封面 + 大量控制按钮”的笨重媒体组件，将多媒体状态收敛为极简的**“状态胶囊（Pill）”**。

*   **视觉呈现**：当播放音乐时，灵动岛收缩为紧凑的胶囊形态（如仅展示微缩专辑切片或单色波形动画）。
*   **隐式交互（无需精准点按的盲操）**：
    *   **左键单击胶囊主体**：播放/暂停 (Play/Pause)。
    *   **滚轮上/下滚动**：上一首/下一首 (Previous/Next)。
    *   **二次交互（如长按或特定操作）**：才展开为详尽的控制面板或显示完整歌词/歌名。
*   **收益**：UI 完全不喧宾夺主，把屏幕空间还给工作区，极大降低用户的定位与认知负荷。

### 2. Niri 工作区空间感：高频收敛与双轨制剥离

Niri 的卷轴特性（无限横向平铺）是对“空间位置感”要求极高的设计。为了防止频繁的焦点切换导致灵动岛不断触发进出场动画（造成“高频动效污染”），我们对空间指示进行剥离：

*   **高频/短距离滚动（常态）**：**不进入灵动岛**。将日常的窗口/工作区焦点切换交由状态栏尽头极简的组件（线段、圆点或微小亮斑）来指示。这部分利用用户的“周边余光”建立物理拓扑直觉，不打扰视觉核心区。
*   **低频/长距离跳转（重磅事件）**：如跨屏跃迁、插拔显示器等，使用屏幕中上方的独立 Toast OSD 气泡进行瞬态通知，并在 2 秒后自然消散。

### 3. 状态互斥的终极解：动态扩容与降级发光

当系统中存在持续渲染状态（如媒体播放胶囊），突然插入高优瞬态事件（如调节音量、收到新消息）时，采用“融合+共同膨胀”策略解冲突，而不是粗暴地来回闪烁替换。

*   **物理弹性延展**：不打断当前的打底状态（如媒体胶囊不收缩），而是让灵动岛向一侧（如左侧）额外延伸出约 30% 的“临时加建区域”。
*   **高优事件降级呈现**：在加建区域内，不铺排完整信息，而是使用极简指示。例如：
    *   调音量时：额外的区域浮现一段微型进度条滑动。
    *   来通知时：角落亮起带有应用主题色的光晕或图标徽标。
*   **平滑回缩**：瞬态操作（2秒）结束后，加建区域应用统一的 `Theme.anim.spring` 弹性动画平滑缩回，恢复最初的打底胶囊状态。

## 架构落地约束 (Architecture Constraints)

1.  **事件仲裁中心**：`SuperIslandService` 必须维护一个状态机与优先级队列，所有视觉模块（通知、亮度、媒体）的形变请求必须向其提交，由岛来统一分配时间片和形态。
2.  **动画同频共振**：所有岛的延伸与收缩动效，必须严格绑定 `Theme.anim.*`。
3.  **单点聚光绝对原则**：在同一主屏幕内，绝对禁止两个及以上的组件在同一时刻进行高调的外扩形变。
