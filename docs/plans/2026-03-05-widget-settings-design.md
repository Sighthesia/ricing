# Widget Settings Panel — Design

**Date:** 2026-03-05  
**Status:** Approved  
**Scope:** Right-click context menu on individual widgets; per-widget settings panel; widget config persistence.

---

## 1. Goals

1. Right-clicking a widget opens an extended `BarContextMenu` that includes widget-specific actions.
2. Clicking "组件设置" auto-enters layout mode and opens a floating panel anchored below the bar, horizontally centred on the target widget.
3. The panel exposes universal appearance overrides, a per-widget extensible config slot, and lifecycle actions (delete, copy, import/export).
4. Per-widget configuration is persisted in a separate `widget-config.json` file to keep it decoupled from the layout file.

---

## 2. Architecture Overview

### 2.1 New Files

| File                                                  | Kind                | Responsibility                                                                         |
| ----------------------------------------------------- | ------------------- | -------------------------------------------------------------------------------------- |
| `services/WidgetConfigService.qml`                    | `Singleton`         | Read/write `widget-config.json`; expose `get(instanceKey)` / `set(instanceKey, patch)` |
| `modules/bar/WidgetSettingsPanel.qml`                 | `AnimatedPanelBase` | Bubble panel anchored below the bar, X-aligned to target widget centre                 |
| `modules/bar/widgetsettings/AppearanceSection.qml`   | `Item`              | Colour pickers, corner radius, padding sliders                                         |
| `modules/bar/widgetsettings/WidgetConfigSection.qml` | `Item`              | Extensible per-widget-type config slot (placeholder for now)                           |
| `modules/bar/widgetsettings/WidgetActionsBar.qml`    | `Item`              | Import / Export / Delete buttons                                                       |

### 2.2 Modified Files

| File                               | Change                                                                                                                              |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `services/BarLayoutService.qml`    | + `activeWidgetInstanceKey: string`, `widgetSettingsX: real`, `widgetSettingsPanelOpen: bool`; + `instanceKeyAt(modelIndex)` helper |
| `modules/bar/BarWidgetWrapper.qml` | + right-click `TapHandler` → calls `BarContextMenu.showAt(x,y,instanceKey,widgetCenterX)`                                           |
| `modules/bar/BarContextMenu.qml`   | + `_targetWidgetKey: string`; conditionally render widget section (separator + "组件设置", "复制组件", "删除组件")                  |
| `modules/bar/BarWindow.qml`        | + instantiate `WidgetSettingsPanel`                                                                                                 |

### 2.3 Data Flow

```
Right-click BarWidgetWrapper
  → BarContextMenu.showAt(clickX, clickY, instanceKey, widgetCenterX)
  → User clicks "组件设置"
  → BarLayoutService.settingsMode       = true
     BarLayoutService.activeWidgetInstanceKey = instanceKey
     BarLayoutService.widgetSettingsX   = widgetCenterX
     BarLayoutService.widgetSettingsPanelOpen = true
  → WidgetSettingsPanel.active          = true
     Panel X = clamp(widgetSettingsX - width/2, 0, screenW - width)
```

## 3. Data Model

### 3.1 Instance Key

Format: `{widgetId}_{index}` (e.g. `clock_0`, `workspaceWidget_0`).

Generated by `BarLayoutService.instanceKeyAt(modelIndex)`, which counts how many earlier entries share the same `widgetId`.

### 3.2 `widget-config.json` Schema

Stored at `.state/widget-config.json` alongside `layout.json`.

```json
{
  "clock_0": {
    "appearance": {
      "backgroundColor": null,
      "textColor": null,
      "cornerRadius": null,
      "paddingH": null,
      "paddingV": null
    },
    "widgetConfig": {}
  }
}
```

- `null` → use global theme default (no override).
- Non-null → local override, applied by `BarWidgetWrapper` via `WidgetConfigService.get(instanceKey).appearance.*`.
- `widgetConfig` is a free-form object reserved for per-widget-type settings; currently always `{}`.

### 3.3 Clipboard / File Exchange Format

Used by Copy, Import, and Export:

```json
{
  "widgetId": "clock",
  "appearance": { ... },
  "widgetConfig": { ... }
}
```

- **Copy**: serialise to JSON, write to clipboard via `xclip -sel clipboard`.
- **Export**: write to user-chosen path via `zenity --file-selection --save`.
- **Import**: read from user-chosen path via `zenity --file-selection`; apply as a new instance.

## 4. UI Components

### 4.1 `BarContextMenu` Extension

```
property string _targetWidgetKey: ""   // "" = bar background right-click
```

When `_targetWidgetKey !== ""`, append after a `Rectangle` separator:
- **组件设置** — enter widget settings mode
- **复制组件** — copy config JSON to clipboard
- **删除组件** — `BarLayoutService.removeWidget(instanceKey)`

`showAt` signature extended to:
```qml
function showAt(x, y, instanceKey, widgetCenterX)
```

### 4.2 `WidgetSettingsPanel`

Based on `AnimatedPanelBase`:

```
anchors { top: true; bottom: false }
margins { top: Theme.barHeight }
implicitWidth: 320
```

X clamped via `BarLayoutService.widgetSettingsX`:
```qml
x: Math.max(0, Math.min(BarLayoutService.widgetSettingsX - implicitWidth / 2,
                         screenWidth - implicitWidth))
```

Internal `ColumnLayout`:
```
┌──────────────────────────────────┐
│  ◀ 返回布局模式    [组件类型]     │  Header
├──────────────────────────────────┤
│  外观             ▸              │  AppearanceSection (ExpandableGroup)
│    背景色 / 文字色 / 圆角 / 内边距 │
├──────────────────────────────────┤
│  功能             ▸              │  WidgetConfigSection (ExpandableGroup)
│    （当前阶段显示"暂无可用设置"）  │
├──────────────────────────────────┤
│  [ 导入 ]  [ 导出 ]  [ 删除 ]   │  WidgetActionsBar
└──────────────────────────────────┘
```

### 4.3 `BarWidgetWrapper` Extension

Add right-click detection below the existing `HoverHandler`:

```qml
TapHandler {
    acceptedButtons: Qt.RightButton
    enabled: !BarLayoutService.isDragging
    onTapped: (eventPoint) => {
        let key = BarLayoutService.instanceKeyAt(wrapper._modelIndex);
        let barContent = wrapper.findBarContent();
        let pt = barContent ? wrapper.mapToItem(barContent, wrapper.width / 2, wrapper.height) : Qt.point(0, 0);
        contextMenu.showAt(eventPoint.position.x, eventPoint.position.y, key, pt.x);
    }
}
```

`wrapper._modelIndex: int` is a new `required property` injected by the repeater in `BarSection`.

## 5. Interaction Flows

### 5.1 Open Widget Settings

1. User right-clicks a widget → `BarContextMenu` renders with widget section.
2. User clicks "组件设置":
   a. `_dismissTimer.restart()` (130 ms) collapses the context menu.
   b. `BarLayoutService.settingsMode = true`.
   c. `BarLayoutService.activeWidgetInstanceKey = key`.
   d. `BarLayoutService.widgetSettingsX = widgetCenterX`.
   e. `BarLayoutService.widgetSettingsPanelOpen = true`.
3. `WidgetSettingsPanel.active` evaluates to `true` → `AnimatedPanelBase` plays enter animation.
4. Target widget's `_showSettingsOutline` becomes `true` (existing highlight logic, no change needed).

### 5.2 Close Widget Settings

| Trigger                            | Action                                                                                       |
| ---------------------------------- | -------------------------------------------------------------------------------------------- |
| "← 返回" button in panel header    | `widgetSettingsPanelOpen = false`, `activeWidgetInstanceKey = ""`, settingsMode stays `true` |
| "退出布局模式" in bar context menu | `activePanel = "none"` → `settingsMode = false` → panel closes automatically                 |
| Click outside panel (focus lost)   | Same as "← 返回"                                                                             |

### 5.3 Live Preview

- `WidgetConfigService.set(key, patch)` updates in-memory store immediately.
- `BarWidgetWrapper` reads `WidgetConfigService.get(instanceKey).appearance.*` for override values.
- `Behavior on color` / `Behavior on` dimensions animate at `highlightDuration` easing.
- Debounced disk write (500 ms), matching `SettingsService`.

## 6. Open Questions / Future Work

- `widgetConfig` extensibility: each widget type will eventually declare a `settingsComponent` property pointing to a QML component that's loaded dynamically into `WidgetConfigSection`.
- Instance key stability across reorder / add / remove: when the layout changes, keys must be recomputed and the config entries remapped or orphaned entries pruned.
- Copy widget = copy config only; the actual widget insertion still goes through the `WidgetPickerWindow` flow (or a direct "paste" shortcut — deferred to v2).
