# Lock Authentication Surface Design

## 目标

将锁屏密码输入从“壁纸上的悬浮密码卡片”调整为“时间主界面中的按需认证入口”，解决透明渐入、中央直角边框和辅助文案造成的弹窗感，同时保持现有密码输入、PAM 验证和解锁流程不变。

## 设计决策

采用时间主界面加按需输入入口：

- 默认状态只显示小时/分钟、日期和底部锁定入口。
- 小时/分钟复用现有 `RollingClockTime` 翻页时钟；日期显示在时间下方。
- 底部入口是一个完整的圆角矩形，内部只显示锁 SVG。
- 鼠标点击或首次键盘输入后，底部同一个圆角矩形原位变为密码输入框。
- 输入态不显示标题、占位文案、操作提示、验证文案或错误文案。
- 空输入时显示比光标更粗的圆角矩形占位符，而不是文字。
- 输入和删除反馈复用启动器 `OsuTextField` / `OsuTextCaret` 的光标和删除字符下落效果。

## 布局

时间区域位于屏幕中心偏上，认证入口位于屏幕底部：

```text
             12:48
           2026.09.22

       [       锁图标       ]
```

时间区域不得被输入框遮挡。底部圆角矩形在默认态和输入态保持同一中心锚点；输入态只改变宽度、内部内容和状态，不创建悬浮卡片。

## 出现动效

锁屏进场只建立时间主界面和底部入口，不显示密码相关文案。进场分为两个轻量阶段：

1. 锁屏背景完成建立。
2. 时间区域和锁入口以短距离位移或高不透明度完成显示。

点击或首个按键触发入口到输入框的原位 morph。复用 `MotionTokens` 的时长、缓动和 reduced-motion 门控。输入框不从透明状态单独浮现。

## 状态反馈

- 默认状态：圆角矩形使用当前主题表面色，内部只显示锁 SVG。
- 输入状态：锁 SVG 收起，圆角矩形原位变宽成为 `OsuTextField`。
- 空输入：显示比光标更粗的圆角矩形占位符，不显示文字。
- 输入状态：使用密码掩码、`OsuTextCaret` 光标和启动器删除字符下落反馈。
- 验证中：不显示文本，保留输入框位置和内容。
- 验证失败：使用错误色和短距离水平反馈，不显示错误文字。
- 解锁退出：沿认证区域的当前位置退场，确保可中断并保持现有释放锁逻辑。

## 主题与可读性

- 继续使用现有 `SettingsService.effectiveColorScheme` 作为锁屏颜色模式来源。
- 深色和浅色模式分别保证时间、日期、锁图标、输入槽和掩码之间的明确对比度。
- 继续保留壁纸和主题切换期间的稳定底色，避免认证区域依赖壁纸取色后变得不可见。
- 不新增独立配色体系；优先复用 `LazerTheme` 和现有锁屏 fallback token。

## 行为边界

本次设计只改变锁屏视觉结构、交互激活状态和输入反馈，不改变：

- 密码输入方式和键盘焦点行为。
- PAM 验证及失败处理。
- 解锁成功后的退出时机。
- 锁屏背景波浪、截图和壁纸 reveal 流程。
- 多屏锁屏表面创建和销毁逻辑。

## 实现边界

主要改动集中在 `modules/lock/LockSurface.qml`，复用 `modules/bar/widgets/RollingClockTime.qml`、`modules/lazerbar/OsuTextField.qml`、`modules/lazerbar/OsuTextCaret.qml` 和 `modules/lazerbar/icons/lock.svg`。如需抽取布局或状态计算，仅新增纯逻辑辅助，不把认证状态迁移出当前锁屏表面所有权。

## 验证标准

- 浅色和深色模式下，时间、日期、锁图标、输入槽和掩码均清晰可辨。
- 默认状态不显示任何密码相关文本。
- 锁屏进入时不出现“透明卡片逐渐浮现”的观感。
- 底部完整圆角矩形能原位 morph 为输入框。
- 首次鼠标点击或键盘输入均能进入输入态。
- 输入和删除反馈与启动器光标、删除字符下落效果一致。
- 输入内容、验证中、失败和成功退出流程行为保持不变。
- `qmllint` 无新增警告。
- `tst_lock_surface_logic.qml` 保持通过。
