# 设置面板打开波浪进场设计

## 目标

设置面板每次打开时，内容区从空白开始，所有设置项按滚动列中的位置自上而下依次出现：

- 行以既有退场语言的逆过程进场：高度从零展开、淡入、并从左侧 `-8px` 回到原位。
- 分类区块背景与其第一行同拍出现，标题随区块一起淡入。
- 全局节奏为统一波浪：相邻行延迟约 `18ms`，整体时长约 `600ms`，与面板滑入动效重叠。
- 起始有一段短基础延迟（约 `120ms`），让面板滑入先行确立方向感。

## 触发与作用域

- 仅在 `beginSession()`（面板打开）时播放一次。
- 切换分类、搜索过滤、侧栏折叠均不触发。
- `MotionTokens.reducedMotion` 开启时跳过整个编排，所有项直接呈现。
- 进场只改变行的可见几何状态，不改变任何设置值、焦点或滚动目标（滚动位置仍由 `resetScrollState` 归零）。

## 机制

复用搜索重排的稳定实例方案：

- 行与分类区块各持有统一的"揭示保持"状态；保持期间使用与搜索隐藏一致的几何（高度 0、透明度 0、x 偏移 -8）。
- 打开瞬间以禁用过渡的方式直接置为保持态（无收缩动画），随后按波浪延迟逐个释放；释放后走既有的 `slow` 缓动展开。
- 波浪延迟按打开时的静态列表顺序计算，不依赖动画过程中的动态位置。
- 每次打开生成新的编次代号，未完成的上一轮波浪被立即取代，保证连续开关不会叠加或错序。

## 边界

- 进场期间输入搜索关键词：搜索隐藏状态与保持态取同一几何，二者天然兼容，搜索结果立即生效。
- 进场期间点击、滚轮行为不受影响。
- 现有测试契约基于最终状态（计数、可见性恢复），进场过程不影响其结果。

## 测试验收

扩展现有面板测试：

- 打开后各行最终全部恢复完整高度、不透明度与原位（等待波浪完成后断言）。
- 减少动态开启时打开面板，行立即可见且高度完整。
- 连续两次 `beginSession` 后状态依然正确收敛。
